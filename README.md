💬 Cluster Connect – Cloud-Native Real-Time Chat Application

Cluster Connect is a cloud-native real-time chat application built using the MERN Stack. It enables secure one-to-one and group messaging with low-latency communication using Socket.IO. The application leverages modern cloud technologies, including Docker, Redis, Apache Kafka, and Kubernetes, to deliver a scalable, reliable, and high-performance messaging platform.


🚀 Features

- 🔐 Secure User Authentication
- 💬 Real-Time One-to-One Messaging
- 👥 Group Chat Support
- 🟢 Online/Offline User Presence
- 📩 Instant Message Delivery
- ⚡ Redis Caching for Improved Performance
- 📡 Apache Kafka for Event Streaming
- 🐳 Docker Containerization
- ☸️ Kubernetes Deployment
- 📱 Responsive User Interface

⚙️ Installation

Clone the Repository

```bash
git clone https://github.com/yourusername/cluster-connect.git
cd cluster-connect
```

 Install Dependencies

```bash
# Backend
cd server
npm install

# Frontend
cd ../client
npm install
```

 Run the Application

```bash
# Backend
npm start

# Frontend
npm start
```
